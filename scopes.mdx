---
title: "API Scopes"
description: "Scopes for Coalesce Quality API clients and API tokens, and the public API methods each scope allows"
---

Every Coalesce Quality API client and API token has a set of scopes. A scope allows a group of related API methods. A call succeeds when the client or token has at least one of the scopes that its method requires.

Select the smallest set of scopes that covers the methods your integration calls. You select the scopes when you create a client or token in the API settings ([EU](https://app.synq.io/settings/api) · [US](https://app.us.synq.io/settings/api) · [AU](https://app.au.synq.io/settings/api)). The settings list the scopes in the same order as this page.

API clients and API tokens can have 62 scopes. Internal scopes for managed integrations are not on this page.
